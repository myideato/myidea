# 模型下载失败（WinError 10054 / 连接被关闭）

国内访问 Hugging Face 常出现「远程主机强迫关闭了一个现有的连接」。可用以下方式解决：

1. **脚本已内置国内镜像**：`download_model.py` 会自动使用 `HF_ENDPOINT=https://hf-mirror.com`，并带重试，直接再运行一次即可：
   ```bash
   python .\local-llm\download_model.py
   ```

2. **手动指定镜像（可选）**：若仍失败，可在运行前设置环境变量：
   - PowerShell：`$env:HF_ENDPOINT = "https://hf-mirror.com"`
   - CMD：`set HF_ENDPOINT=https://hf-mirror.com`
   然后再执行上述 Python 命令。

3. **使用代理**：如有稳定代理，可先设置 `HTTP_PROXY`/`HTTPS_PROXY`，再运行下载脚本。

# 图像打标执行命令

在项目根目录（如 `D:\ai\myidea`）下执行。有 NVIDIA 显卡时会自动使用 GPU，速度更快。

## 单张图片打标（推荐，自动用 GPU）

```bash
python .\local-llm\image_tagger.py --model_path .\deepseek_vl_model\ --image test.png
```

## 更快：缩短生成长度

```bash
python .\local-llm\image_tagger.py --model_path .\deepseek_vl_model\ --image test.png --max_tokens 150
```

## 强制使用 CPU（无显卡或指定用 CPU 时）

```bash
python .\local-llm\image_tagger.py --model_path .\deepseek_vl_model\ --image test.png --device cpu
```

## 强制使用 GPU

```bash
python .\local-llm\image_tagger.py --model_path .\deepseek_vl_model\ --image test.png --device cuda
```

## 批量处理目录中的图片

```bash
python .\local-llm\image_tagger.py --model_path .\deepseek_vl_model\ --batch_dir 图片目录路径 --output tags.json
```

## 常用参数说明

| 参数 | 说明 | 示例 |
|------|------|------|
| `--model_path` | 本地 DeepSeek-VL 模型目录 | `.\deepseek_vl_model\` |
| `--image` | 单张测试图片路径 | `test.png` |
| `--batch_dir` | 批量处理时的图片目录 | 任意目录路径 |
| `--output` | 批量结果输出 JSON 文件 | `tags.json` |
| `--device` | 设备：`cuda` 或 `cpu`，不传则自动检测 | `cuda` / `cpu` |
| `--max_tokens` | 生成描述最大 token 数，越小越快 | 默认 `256`，可设 `150` |
