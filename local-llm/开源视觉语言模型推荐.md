# 开源视觉语言模型推荐


---

## 一、偏高质量 / 结构化输出（类似 DeepSeek-VL）

| 模型 | 参数量 | 显存 | 特点 |
|------|--------|------|------|
| **DeepSeek-VL** | 7.3B | ~24GB | 细粒度、多字段、中文结构化打标，支持 JSON 模板 |
| **Qwen2-VL / Qwen2.5-VL** | 7B～72B | ~12GB+ | 阿里开源，中文友好，支持 JSON 等结构化输出，适合表单、文档 |
| **InternVL2 / InternVL2.5** | 2B～76B | 按规模 | 多模态能力强，支持文档、医学等，InternVL2.5 在 MMMU 上表现突出 |
| **LLaVA-NeXT** | 7B～110B | 按规模 | 基于 LLaMA3/Qwen 等，多模态能力较强，生态成熟 |
| **CogVLM2** | 17B | ~24GB | 文档理解、OCR 表现好，适合复杂图文任务 |
| **PointLLM** | 按规模 | 按规模 | **点云专用**，彩色点云理解、3D 分类与描述，开源+预训练权重 |
| **GPT4Point** | OPT 2.7B 级 | 按规模 | **点云专用**，点云 caption、QA、可控 3D 生成，开源+预训练权重 |

---

## 二、轻量 / 资源受限（类似 BLIP2）

| 模型 | 参数量 | 显存 | 特点 |
|------|--------|------|------|
| **BLIP2** | 2.7B+ | 7～14GB，可 CPU | 轻量部署、CPU 友好、简单 caption/VQA |
| **MiniCPM-V 2.0** | 3B | 约 9～12GB（量化可更低） | 端侧部署，中英双语，3B 在部分 benchmark 上接近 9B 模型 |
| **Moondream** | ~1.8B | 约 4GB | 非常轻量，适合简单描述、VQA |
| **LLaVA-Phi** | 3B | 约 4GB | 基于 Phi，推理快，适合简单图文任务 |
| **Phi-3-Vision** | 4.2B | 约 8GB | 微软小模型，图文理解能力不错 |
| **Text4Point** | 较小 | 按规模 | **点云专用**，CLIP 语言监督、点云表示学习，开源 |
| **VG4D** | 按规模 | 按规模 | **4D 点云视频**，动作识别，开源 |

---

## 三、按场景的简单推荐

- **需要高质量、多字段、中文结构化打标**：**DeepSeek-VL**、**Qwen2.5-VL**、**InternVL2.5**
- **显存 12GB 左右**：**MiniCPM-V 2.0**、**Qwen2-VL** 7B 量化版
- **显存 8GB 以下 / CPU 推理**：**Moondream**、**LLaVA-Phi**、**BLIP2**
- **文档 / OCR 为主**：**Llama 3.2 Vision**、**CogVLM2**、**InternVL**

---

## 四、按输入类型适用性（图片 / 视频 / 点云）

### 图片（Image）

文档中的模型均支持图像输入，适合描述与结构化打标。

- **结构化打标推荐**：**DeepSeek-VL**、**Qwen2.5-VL**、**InternVL2.5**、**CogVLM2**
- **轻量 / 简单描述**：**BLIP2**、**MiniCPM-V**、**Moondream**、**LLaVA-Phi**、**Phi-3-Vision**

### 视频（Video）

仅部分模型原生支持视频输入：

| 模型 | 视频支持 | 说明 |
|------|----------|------|
| **Qwen2-VL / Qwen2.5-VL** | ✅ | 原生支持视频，Qwen2.5-VL 可处理长达数小时（约 1 小时），M-ROPE 处理时序 |
| **InternVL2** | ✅ | 支持 text、image、video、medical 等多模态输入 |
| **CogVLM2-Video** | ✅ | 视频专用版本，约 1 分钟视频，需单独模型 |
| **DeepSeek-VL** | ❌ | 仅图像 |
| **BLIP2** | ❌ | 仅图像 |
| **LLaVA / MiniCPM-V / Moondream 等** | ❌ | 默认仅图像 |

**视频场景推荐**：**Qwen2.5-VL**、**InternVL2**；短视频可考虑 **CogVLM2-Video**。

### 点云（Point Cloud）

| 模型 | 说明 |
|------|------|
| **PointLLM** | 彩色点云理解，3D 物体分类与描述 |
| **GPT4Point** | 点云-语言理解与生成，caption、QA、可控 3D 生成 |
| **Text4Point** | 清华 LeapLab，CLIP 等语言监督 |
| **VG4D** | 4D 点云视频，动作识别 |

### 简要对照

| 输入类型 | 文档中是否支持 | 推荐 |
|----------|----------------|------|
| **图片** | 全部支持 | 结构化打标：DeepSeek-VL、Qwen2.5-VL、InternVL2.5 |
| **视频** | Qwen2-VL、InternVL2、CogVLM2-Video | Qwen2.5-VL、InternVL2 |
| **点云** | PointLLM、GPT4Point、Text4Point、VG4D 支持 | PointLLM、GPT4Point（描述/打标）；Text4Point、VG4D（表示学习/动作识别） |
