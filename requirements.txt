# 两套 RAG 同时安装时 pip 容易报 resolution-too-deep，请按需安装：
#
# 只用 LlamaIndex（rag_llamaindex.py）：
#   pip install -r requirements-llamaindex.txt
#
# 只用 LangChain（rag_langchain.py）：
#   pip install -r requirements-langchain.txt
#
# 若需同时使用两套，请分两步安装：
#   pip install -r requirements-llamaindex.txt
#   pip install -r requirements-langchain.txt
#
# 或用 uv 一次性安装（解析器更强）：
#   uv pip install -r requirements-llamaindex.txt -r requirements-langchain.txt
